# Meu Site Pessoal | Programação Web

Fiz este projeto para colocar em prática o que estudei na apostila de Programação Web do meu curso Técnico em Informática para Internet. O objetivo foi criar uma página simples e funcional do zero, testando o HTML na prática.

Dividi o site em duas partes:

A primeira página é onde me apresento, falo da minha rotina dividida entre o trabalho e os estudos, mostro os meus principais gostos e deixo os links de contacto.

A segunda página serve para contar as coisas com mais calma. Nela detalho a minha trajetória, o que ando a aprender na área de informática e o que curto fazer no meu tempo livre fora do computador, como acompanhar o mundo dos carros, colecionar miniaturas e praticar aeromodelismo com drones.

Pagina feita por Luigi Ezequiel.
