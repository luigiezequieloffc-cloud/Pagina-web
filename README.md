Página Web – Atividade de Programação Web

Fiz este projeto para colocar em prática o que estudei na apostila de Programação Web do meu curso Técnico em Informática para Internet. O objetivo foi criar uma página simples e funcional do zero, testando o HTML na prática.

Sobre o projeto

Dividi o site em duas partes:

A primeira página é onde me apresento, falo da minha rotina dividida entre o trabalho e os estudos, mostro meus principais gostos e deixo os links de contato.

A segunda página serve para contar minha trajetória com mais detalhes. Nela apresento o que estou aprendendo na área de informática e o que gosto de fazer no meu tempo livre fora do computador, como acompanhar o mundo dos carros, colecionar miniaturas e praticar aeromodelismo com drones.

1ª Atualização – Criação das páginas
- Criada a página inicial com minha apresentação pessoal.
- Adicionada uma segunda página com informações sobre minha trajetória e meus hobbies.
- Criados links para facilitar a navegação entre as páginas.

2ª Atualização – Formulário de contato
- Adicionados campos para nome, e-mail e telefone.
- Incluído um botão para enviar o formulário e outro para limpar os dados preenchidos.

- Adicionada a estilização com CSS para definir as cores e a aparência visual das páginas.
- Organizados os elementos e a navegação.

4ª Atualização – CSS Grid e Flexbox
- Mantidas a estrutura e as informações da página anterior.
- Adicionada a seção **Tecnologias e Interesses**.
- Criados quatro cartões sobre HTML, CSS, Informática e Veículos e Drones.
- Utilizado CSS Grid para organizar as seções e os cartões.
- Utilizado Flexbox para organizar os elementos internos dos cartões e as tags.
- Adicionados ajustes de responsividade para melhorar a visualização em celulares e telas menores.
